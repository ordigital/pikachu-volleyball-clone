Навіщо це все

Pikachu Volleyball — одна з моїх улюблених ігор у ліцеї, у яку я грав після уроків, тому вирішив зробити її ремейк. Це той самий швидкий і простий волейбол, перемальований у високій роздільній здатності та написаний на Rust, а потім зменшений до 8 і 16 біт для консолей тієї епохи. Під час роботи над грою я користувався інструментами ШІ.

Фізика й комп'ютерний суперник відтворюють логіку оригінальної гри, тож м'яч поводиться так, як ви пам'ятаєте. Обирайте 1 гравця проти комп'ютера або 2 гравців на одному пристрої. Перемагає той, хто першим набере 15 очок.

  • 1 або 2 гравці
  • Логіка оригіналу
  • Безкоштовно
  • Відкритий код

Оберіть платформу

Остання версія: …  ·  кнопки завжди ведуть до найновіших файлів.

Linux

  • AppImage для x86-64 та ARM64; зробіть файл виконуваним і запустіть.
  • Потрібні glibc 2.34+ та системні бібліотеки ALSA, X11 і OpenGL/EGL. Немає FUSE? Запустіть із APPIMAGE_EXTRACT_AND_RUN=1.
  • Клавіатура, геймпади та сенсорні екрани. Гравець 1: D G R F Z, гравець 2: стрілки + Enter. F11 вмикає повний екран. Клавіші можна змінити.
⬇ x86-64 AppImage⬇ ARM64 AppImage

Windows

  • Завантажте ZIP, розпакуйте й запустіть pikachu-volleyball.exe. Встановлення не потрібне.
  • Геймпади XInput (сумісні з Xbox) і клавіатура, керування те саме, що в Linux.
  • Файл без цифрового підпису: Windows SmartScreen може попросити підтвердження.
⬇ Windows x64 ZIP

Android

  • Окремий APK для ARM64 та ARMv7, Android 5.0 або новіший. Немає в Google Play: встановіть файл напряму.
  • Невидиме плаваюче керування: тягніть, щоб бігти, тягніть угору, щоб стрибнути, торкніться іншої половини екрана, щоб вдарити або кинутися. Режими для правшів і лівшів.
  • Підключений геймпад визначається автоматично.
⬇ Android APK

Sega Mega Drive / Genesis

  • Незалежний порт, написаний на C із SGDK. Стандартний ROM на 4 МіБ: без маппера та пам'яті збережень.
  • Оригінальна MIDI-музика на YM2612 і PSG; піксельну графіку перероблено під 320×224.
  • Напрямки: рух, стрибок (вгору) і приціл (вниз); B б'є або кидається; Start — пауза.
⬇ Mega Drive .bin ROM

Nintendo Entertainment System (NES)

  • Незалежний порт на C та асемблері 6502 (картридж MMC3). NTSC і PAL визначаються автоматично.
  • Гравці 32×32 і м'яч 24×24 — найбільші, які дозволяє обмеження у вісім спрайтів на рядок; оригінальна музика аранжована для APU, голоси — як семпли DPCM.
  • Хрестовина: рух, A або B б'є або кидається; Start — пауза. Другий геймпад для другого гравця.
⬇ NES .nes ROM
